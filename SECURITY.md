# Security reporting

Report suspected vulnerabilities privately to [mike.jung.global@gmail.com](mailto:mike.jung.global@gmail.com). Include the affected version, platform, reproduction steps and expected impact. Remove passwords, tokens, private keys and personal device information.

Do not disclose credentials or exploitable details in a public GitHub issue. Public issues are suitable for ordinary defects with sanitized reproduction steps. Use the latest supported release and consult the release notes before upgrading.

HTTPS, authentication, administrator permissions, device approval, revocation and audit logging are part of the Public edition. Enterprise HA does not replace secure configuration, backups or access control.
